## Overview

Streams UI provides Blade components and Livewire-driven builders for tables, forms, and layout. Use them inside panels or embed in your own views.

## Patterns

- **Panel pages** — full CP sections with navigation
- **Embedded tables** — list stream entries with filters and actions
- **Custom Livewire** — extend UI builders when JSON is not enough

Streams remains Laravel-native: standard views, middleware, and authorization apply.
