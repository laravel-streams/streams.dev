Agentic-first packages for Laravel and the TALL stack

Laravel, described in configuration.

Model your domain as streams in JSON. Query it through one criteria API, render it with Blade and Livewire, and let people and AI agents build on it with predictable, consistent results.

How it works

One file per domain. Everything else follows.

  1. 1

    Describe a stream

    Fields, routes, and storage live in streams/*.json, versioned with your code.

  2. 2

    Add entries

    Flat files, JSON, or a database. The storage adapter can change without touching application code.

  3. 3

    Query, route, and render

    Criteria queries, stream routes, admin UI, and a REST API all read the same definition. This site is built exactly this way.
